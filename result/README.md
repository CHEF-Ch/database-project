# 验证证据

> 存放实际运行验证的输出：sqlcmd 执行结果、非法数据被拒绝、越权操作失败、查询结果正确等。

- 命名建议：`sql-validation.txt`（sqlcmd 输出）、截图按场景命名
- 检查标准：看最后一行是否为预期的 `PASS` / `ALL TESTS PASSED`，同时检查 sqlcmd **退出码为 0**（不能只看文本）
- 样例数据必须虚构，不包含真实姓名 / 联系方式 / 支付信息
