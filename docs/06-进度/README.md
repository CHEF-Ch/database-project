# 进度与状态

> 按周记录任务流程与完成状态，供组内同步进度用。任务内容与交付标准的正式说明仍以 `docs/0X-*.md` 为准，本目录只回答"做到哪一步了、谁在做"。

| 文件 | 覆盖范围 |
| --- | --- |
| [`第二周任务流程与状态.md`](第二周任务流程与状态.md) | 第二周：关系模式与数据字典（`docs/02`） |
| [`第三周任务流程与状态.md`](第三周任务流程与状态.md) | 第三周：建库建表、样例数据装载、增删改查、复现验证（`sql/`） |
| [`第四周任务流程与状态.md`](第四周任务流程与状态.md) | 第四周：查询、视图、约束、角色权限与阶段验收（`sql/query.sql` 等、`result/`） |
| [`第五周任务流程与状态.md`](第五周任务流程与状态.md) | 第五周：ER 模型（实体/联系/基数/参与约束，第二阶段 v1.0 起） |

## 约定

- 每完成一步即更新状态，并提交一次（提交人 = 完成者），便于对照 `docs/05-组内分工.md` 的"实际贡献与提交证据"。
- 状态取值固定为四个，避免各人写法不一：**未开始 / 进行中 / 待复核 / 已完成**。
