## 协作约定

- 代码仓库地址：<https://github.com/CHEF-Ch/database-project>
- 提交规范：提交信息写明"第 X 周 + 步骤号 + 做了什么"；**每位成员用各自的 Git 身份提交**，便于 `git log` 追溯贡献。
- 分支策略：**当前在 `main` 上直接提交**。已在第 2 周出现过一次分叉（两人各自基于同一提交推进，后推者需先 `pull --rebase`）——推动前先 `git pull --rebase origin main`，有冲突当次解决。若后续多人同时改同一份文档（如 `docs/02`）导致冲突频繁，再引入 `feature/*` 分支。
- **跨人复核**：涉及表结构、业务规则等关键产出的修改，由**另一名成员**复核后再提交或回改，复核结论记入 `docs/04-AI使用记录/`。
